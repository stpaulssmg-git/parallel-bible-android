Apostolic Parallel Bible

Version 1.0

An offline, dual-pane parallel Bible study application designed for fast side-by-side translation comparison, verse searching, and responsive reading. This application is 100% free and contains no ads.

Supported Translations

  • KJV - King James Version
  • NAS - New American Standard
  • LXX - Thomson Septuagint
  • ABe - Apostolic Bible (English)
  • ABg - Apostolic Bible (Greek)
  • T4T - Translation for Translators

Key Features

  • Side-by-side parallel verse comparison
  • 7 study translations (KJV, NAS, H/G, LXX, ABe, ABg, T4T)
  • Accordion book & chapter selector divided by OT & NT
  • 100% clean English book names with expandable chapter grid
  • Fast offline SQLite full-text search
  • Right-to-Left (RTL) Hebrew text rendering
  • Horizontal swipe gesture chapter navigation
  • Pinch-to-zoom gesture text scaling & theme customization
